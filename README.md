# VIOLET — демонстрационная версия сайта

Готовый автономный прототип нового сайта производителя стеновых и потолочных панелей. Для просмотра не нужна установка программ и не нужен интернет.

## Как открыть

Самый простой способ — дважды нажать `index.html`. Он откроется в браузере. Все внутренние страницы систем и проектов работают и при таком просмотре.

Для удобной отладки можно дважды нажать `start-preview.command`. Откроется локальная версия сайта по адресу `http://localhost:8765`. Окно терминала должно оставаться открытым во время просмотра; для остановки нажмите в нём `Control + C`.

## Что где редактировать

- `index.html` — главная страница.
- `decors.html` — полный локальный каталог покрытий и декоров.
- `system.html` и `project.html` — шаблоны подробных страниц систем и проектов.
- `css/styles.css` — базовый внешний вид; `css/revision.css` — новый визуальный слой; `css/detail.css` — внутренние страницы.
- `js/catalog-data.js` — единый каталог систем, проектов, характеристик и локальных фотографий.
- `js/decor-catalog-data.js` — 768 декоров, их коды, названия, серии и локальные изображения; `js/decors.js` — поиск, фильтры и крупный просмотр.
- `js/app.js` — меню, фильтры, формы и калькулятор; `js/system.js` и `js/project.js` — галереи внутренних страниц.
- `assets/images` — официальный логотип, фото систем, портфолио и производства.
- `assets/SOURCES.md` — список официальных интернет-источников материалов.
- `assets/favicon.svg` — иконка вкладки браузера.

## Что работает

- подбор системы по типу объекта;
- фильтр продуктовых систем и подробная страница каждой системы;
- 13 продуктовых систем, включая древесноволокнистые, потолочные и фасадные панели;
- конструктор декоров внутри каждой системы: один интерьер и переключаемые древесные, изысканные и однотонные покрытия;
- полный каталог из 768 образцов в пяти категориях с поиском и фильтрацией по сериям;
- полноэкранное увеличение фотографий систем с листанием;
- фильтруемое портфолио из десяти объектов и отдельные фотогалереи проектов;
- выезжающее боковое меню на телефоне;
- вкладки библиотеки для специалистов;
- формы-заглушки без отправки данных;
- пятишаговый калькулятор площади, запаса и количества листов;
- скачивание текстового резюме расчёта;
- адаптивная версия для телефона и планшета.

## Важно

Это демонстрационная концепция, а не официальный сайт VIOLET. Формы никуда не отправляют данные, документы в библиотеку не вложены, а расчёт требует проверки инженером.
